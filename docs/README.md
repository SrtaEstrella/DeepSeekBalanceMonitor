# 文档

这个分支是 1.x 的 Python 实现，目前只放一份接口文档：

- [`INTERFACES.md`](INTERFACES.md) —— **Rust 实现（`dsmon2`，2.x）与将来的 Python 实现必须共同暴露的
  接口**：本机只读数据接口、`config.json`、状态目录与数据库、单实例名、开机自启、平台清单、命令行。
  只要按第 1 节实现，桌面小工具（`dsmon2-widget`）就能直接读你的数据，**小工具一行都不用改**；
  第 2–7 节是两版能在同一台机器上共存、共用同一份用户数据的前提。

## 这份文档从哪来

它是从 2.x 的开发分支 **`rust-gui`** 复制过来的——那份是**唯一来源**，随代码变化更新。这个分支上
读它请当作快照看待。

**与之配套、但不在本分支**的文档还有（都在 `rust-gui` 的 `docs/` 下）：

| 文档 | 内容 |
|---|---|
| `WIDGET.md` | 桌面小工具的设计与实现说明（数据从哪来、端点在做什么、界面规则） |
| `PLATFORM_PORTING.md` | 各订阅平台的接口细节（端点、字段、易错点） |
| `GAPS.md` | 1.x 与 2.x 的差异、尚未移植的功能 |

## 改动规则

接口要变时，**先改 `rust-gui` 分支的那一份**（它是来源，也要同步升 `version`），再把本文件复制过来。
两边不一致时，以 `rust-gui` 为准。
